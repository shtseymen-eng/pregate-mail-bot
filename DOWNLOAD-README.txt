Pregate Mail Bot v1.2.6 - Windows x64

Requires Windows 10/11, installed Google Chrome, and classic Microsoft Outlook configured with your account. Outlook for Mac and new Outlook are not supported by this COM-based application.

Installer: run PregateMail_Kurulum.exe.
Portable: extract the entire ZIP to a writable folder, then run PregateMail.exe.
Configure the WhatsApp group, rules and recipients before starting the bot. The package contains no customer data, browser profile or configured recipients.
The application is unsigned.
